🛠️ Daftar Fitur Baru yang Berhasil Ditambahkan
1. Panel Kontrol Bingkai Gambar (Picture Border Panel)
Toggle On/Off (Checkbox): Memungkinkan pengguna untuk memilih apakah ingin mengaktifkan bingkai pada gambar atau membiarkannya polos (tanpa bingkai).
2. Kustomisasi Ketebalan Garis (Border Weight)
Dropdown Ketebalan: Pilihan ketebalan garis standar (dengan default 1 pt) yang dapat disesuaikan dengan kebutuhan dokumen resmi.
3. Kustomisasi Warna Garis (Border Color)
Preset Tombol Warna Cepat: Akses 1-klik untuk warna-warna populer dan resmi:
Hitam
Abu-abu
Biru BCA (selaras dengan tema laporan BCA)
Merah
Custom Color Picker: Kotak pemilih warna manual untuk memilih warna kustom secara bebas menggunakan kombinasi HEX/RGB.
